🎁 Розіграш в Instagram

Учасники: усі, хто підписаний і залишив коментар з позначкою під постом. Коментарі підтягуються через Instagram Graph API. Токен залишається лише у вашому браузері.

1Підключення акаунта

Де взяти токен?

Від замовника потрібен лише доступ до Instagram. Застосунок Meta створюєте ви на своєму акаунті й використовуєте для всіх замовників.

А. Один раз: ваш застосунок

  1. Зайдіть на developers.facebook.com зі свого Facebook і зареєструйтеся як розробник.
  2. My Apps → Create App → use case «Manage messaging & content on Instagram». Бізнес-портфоліо можна не підключати.
  3. Use cases → Customize → у Permissions додайте instagram_business_basic і instagram_business_manage_comments.

Б. Для кожного замовника

  1. Акаунт замовника має бути професійним (Автор або Бізнес): у застосунку Instagram ☰ → Тип акаунта та інструменти. Facebook для цього не потрібен.
  2. У вашому застосунку: App roles → Roles → Add People → Instagram Tester → нік замовника.
  3. Увійдіть в Instagram замовника на instagram.com → Налаштування → Сайти та застосунки → Запрошення тестувальника → прийміть.
  4. У застосунку: API setup with Instagram login → Generate access tokens → Add account → вхід під Instagram замовника → Allow → Generate token.
  5. Скопіюйте токен (починається з IGAA) і вставте сюди. Токен діє близько 60 днів.

Підписники для перевірки підписки

Поки маєте доступ до акаунта, замовте архів заздалегідь (готується від кількох хвилин до кількох годин): Центр облікових записів → Ваша інформація та дозволи → Завантажити інформацію → лише «Підписники та підписки», формат JSON. Потрібний файл: followers_1.json.

Безпека

  • Код підтвердження входу прийде замовнику, тож зручно робити все разом на дзвінку.
  • Нікому не пересилайте токен. Після розіграшу замовник може прибрати доступ: Налаштування → Сайти та застосунки, а також змінити пароль.

Не виходить з API (акаунт не можна зробити професійним тощо)? Скористайтеся ручним режимом унизу сторінки: скопіюйте коментарі з поста й вставте їх туди.

Альтернатива: токен Facebook (EAA…) з Graph API Explorer з дозволами instagram_basic, instagram_manage_comments, pages_show_list, якщо Instagram прив'язаний до сторінки Facebook.

3Умови

Instagram API не віддає список підписників. Щоб перевіряти підписку автоматично, завантажте файл followers_1.json або .html з архіву даних Instagram (Налаштування → Центр облікових записів → Ваша інформація → Завантажити інформацію → «Підписники та підписки»). Або вставте ніки списком. Без списку підписку переможця перевіряєте вручну кнопкою.
